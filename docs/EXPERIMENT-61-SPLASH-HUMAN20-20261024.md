## Initial Default Budget Failure (Before Formal Question Group)

After Splash read the weights, it was rejected by the memory planner when creating the minimum state/KV workspace, exited, and did not enter Ready. Original diagnosis:

|Item|bytes|GiB|
|---|---:|---:|
|Physical Memory|51,539,607,552|48.000|
|Metal recommended working set|40,200,896,512|37.440|
|Planner reserved margin|1,073,741,824|1.000|
|hard budget|39,127,154,688|36.440|
|target weights|36,901,766,144|34.368|
|fixed runtime|39,013,279,104|36.334|
|minimum required|39,279,945,088|36.582|
|gap|152,790,400|0.142|

Error is `resource_assembly/memory_planning` / `kv_pool_does_not_fit`: `hard budget cannot fit one lane's state and the KV runway`, followed by `native protocol reached EOF`. This is a definitive startup capacity rejection, not a timeout, decoding crash, or OOM after running. Even if only the minimum required is met, it does not mean 32K KV can be loaded; one cannot infer that slightly increasing memory will complete this test from the 0.142 GiB gap.

## Observing Adapter Verification and Timing Limits

The adapter reuse in PR #62 uses the existing Pi harness, does not modify model prompts, and adds independent `cache_salt`, temperature=0, reasoning_effort=none to each request. Synthetic HTTP/SSE fixtures verified different cache namespaces for two requests, response passthrough, usage/timing saving, role events not counting as the first token, and observation logs not saving prompts or answers. This fixture only verifies the collector and never serves as inference performance data.

Splash's `/status.metrics` is the cumulative count of native executor commands; during serial exclusive use, calculation throughput can be obtained via the difference before and after each request. The `metrics.request_latency` of the final response is the native request lifecycle; DFlash2 for the first emission can contain multiple tokens, the decode numerator is `metrics.decode.tokens`, and it cannot be directly changed to N−1. The standard SOP's first-to-last token N−1 speed must be marked as not obtained when there is no equivalent observation. The two metrics should be reported separately; HTTP block intervals or Pi wall time cannot be used as worker timing.
